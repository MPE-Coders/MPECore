# MPECore

Монорепозиторий экспериментального Minecraft Bedrock-сервера: Rust-движок,
PHP/RakLib-шлюз, PHP Plugin API и отдельный headless-клиент.

**Вход официальным клиентом 1.26.20 подтверждён владельцем проекта.** Пока
доступен ограниченный Creative на плоском мире; полного Survival нет.
Это не законченный релиз и не обещание полной ванильной совместимости.

## Текущее обновление

- Локальная подготовка Node 24.21.0 при системном Node 22 без изменения ОС.
- Инкрементальные UpdateBlock вместо повторной отправки чанка после каждого блока.
- `/mpe perf`: счётчики пакетов и время обработки последних 256 игровых действий.
- План развития: [docs/DEVELOPMENT_PLAN.md](docs/DEVELOPMENT_PLAN.md).
- Запуск и диагностика: [docs/NODE_RUNTIME.md](docs/NODE_RUNTIME.md).
- Данные 2193: [docs/BEDROCK_26_51.md](docs/BEDROCK_26_51.md).

## Исходники

`src/` — Rust-мир, игроки, чанки, плоский генератор, журнал и IPC.
`gateway/` — PHP/RakLib, авторизация, кодеки, палитры, Creative-инвентарь,
консоль и хост плагинов. `plugins/` — примеры PHP-плагинов.
`test-client/` — отдельный RakNet-клиент и сценарии.
`tests/` и `.github/workflows/` — тесты, сборки и воспроизводимые логи.
`resources/` — канонические блоки и явные профили; `tools/` — запускатели.

## Запуск

```bash
./start.sh --unit
./start.sh --playtest --version 1.26.20
```

Для 1.26.50/1.26.51 используется протокол 2193 и временный Node-кодек:

```bash
./tools/node-install.sh
./start.sh --playtest --version 1.26.51
```

Нужны Rust/Cargo >=1.74, Python >=3.10 и PHP >=8.2 с ext-encoding.
Штатные скрипты подготавливают PHP-runtime и при необходимости Node >=24
внутри проекта. Первая установка требует Интернета. Системный Node не заменяется.

Исправлены прежние блокеры: несогласованный metadata-файл 1001, окружение
OpenSSL, утечка PHP-библиотек в Node и версия/порядок запуска тестового RakNet.
Смотрите результаты Actions для точного коммита, не исторический отчёт.

```bash
./tools/e2e.sh --version 1.26.20 --scenario creative
./tools/e2e.sh --version 1.26.51 --scenario creative
```

Плейтест с официальным клиентом использует online-авторизацию. E2E — отдельный
loopback-сервер с offline-идентичностью и включённым шифрованием. Это разные
проверки. Официальный вход 1.26.51 ещё не подтверждён. Полного набора механик,
обычной генерации, мобов, редстоуна и измерений пока нет.

`TEST_REPORT.md` — исторический отчёт исходного архива, не результат последнего
коммита. Не публикуйте JWT, `.client-auth`, приватную конфигурацию, рабочие карты
и логи с персональными данными.
