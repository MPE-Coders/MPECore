# PHP-плагины

Примеры находятся в `plugins/Welcome` и `plugins/Commands`. Это собственный API, знакомый по стилю PMMP, но не совместимость со всеми готовыми PMMP PHAR.

```text
plugins/Welcome/
  plugin.json
  src/Main.php
```

PluginBase, Player, Vector3 и классы событий находятся в gateway/src/. PHP-файл можно изменить без пересборки Rust. Команда серверной консоли `reload Welcome` заменяет процесс плагина и повторно загружает классы.

PlayerJoinEvent, PlayerChatEvent и PlayerCommandEvent предназначены для обычных обработчиков. BlockChangeEvent отправляется после успешного изменения мира; отменять действие через него нельзя. Для будущих защит регионов нужен отдельный отменяемый pre-commit контракт с deadline и определённой политикой отказа.

Плагины выполняются отдельными процессами, но это не защитная песочница. Запускай только доверенный PHP-код. Инвентарь, транзакции и состояние мира нельзя параллельно изменять обходными путями мимо ядра.

JS/TS/WASM plugin hosts пока не реализованы. В целевой Rust-архитектуре PHP остаётся необязательным host для этих же доступных плагинов, а не обязательной средой исполнения сервера.
