# Обновление исходников

Останови работающий сервер штатно и сохрани резервную копию карты. В клонированном MPECore:

```bash
git status --short
git pull --ff-only origin main
./start.sh --check-source
./start.sh --unit
./start.sh --playtest --version 1.26.20
```

Если Git сообщает о конфликте локальных правок, не выполняй reset --hard или git clean ради обхода ошибки. Сначала сохрани и согласуй изменения. Для папки без .git скачай свежий исходный архив или сделай отдельный clone; не удаляй прежнюю карту.

Исправление StartGame не меняет формат карты и не требует редактирования vendor. Оно не отключает проверки данных, авторизацию или шифрование. После pull обычный start.sh выполняет необходимые проверки и сборку.

В репозитории хранятся source и lock-файлы. vendor, node_modules, .runtime, рабочие миры и секреты — не отсутствующие исходники, а отдельно устанавливаемые зависимости/данные. Не переносить чужой кэш авторизации и не загружать его на GitHub.
