# Переход к нативному Rust-серверу

Целевая архитектура: игровой сервер запускается без PHP. PHP остаётся необязательным отдельным процессом только для PHP-плагинов. JS/TS — отдельный будущий runtime, а не обязательная зависимость игрового ядра.

Сейчас это **не выполнено**. `src/` — Rust-симуляция и сохранение; `gateway/` — обязательный PHP/RakLib-шлюз, авторизация, кодеки, значительная часть инвентарных операций и host плагинов. Это переходная реализация, а не полностью независимый Rust-сервер.

## Последовательность замены

1. Зафиксировать реальный вход, действия и переподключение официального Bedrock 1.26.20/975. Сохранить воспроизводимые тесты пакетов без токенов и приватных ключей. Успешная компиляция не подтверждает вход.
2. Выделить интерфейсы транспорта, версионных кодеков и событий игрового мира. Одна авторитетная модель состояния; не дублировать инвентарь и блоки в новом gateway.
3. Реализовать в монорепозитории Rust NBT/VarInt, типизированные состояния, сжатие и кодеки одного профиля. Сравнивать байты с зафиксированным NetherGames и независимым клиентом. Не переносить ошибки старого кодека как спецификацию.
4. Добавить Rust RakNet/session, ограничение размеров и очередей, авторизацию и шифрование. Криптографические примитивы брать из проверенных библиотек; не писать собственный AES/ECDH ради отсутствия зависимостей.
5. Сделать выбор backend при запуске и прогнать одинаковые E2E-сценарии с PHP-gateway и Rust-gateway. Сравнить результаты и измерить время тика/память/задержки. Пока такого переключателя нет.
6. Перевести default на Rust только после фактического плейтеста; оставить PHP SDK и IPC host для привычных плагинов. Без PHP-плагинов PHP не требуется.

Модули можно организовать как Cargo workspace (`mpe-network`, `mpe-protocol`, `mpe-nbt`, `mpe-auth`, `mpe-world`, `mpe-server`) внутри **MPE-Coders/MPECore**. Сейчас эти имена описывают проектные границы, а не существующие библиотеки.

## Что означает независимость

Независимость от запуска PMMP/PHP и от чужого игрового ядра — полезная цель. Полный отказ от внешних библиотек — другая задача, не требуемая для неё. Данные NetherGames, официальная документация Mojang и Pumpkin могут оставаться проверяемыми источниками и эталонами. Копирование кода требует соблюдения его лицензии; смена языка или репозитория этого не отменяет.

Обновление кодека, версия IPC, формат хранения мира и версия Plugin API должны меняться независимо. Фиксировать Git SHA, lock-файлы и версию генератора в карте. Не обещать выигрыш производительности до измерений.
