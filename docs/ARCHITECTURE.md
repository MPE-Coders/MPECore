# Архитектура MPECore

Весь проект находится в одном репозитории. Это не прокси к скрытому Minecraft-серверу.

```text
Bedrock client -> PHP gateway / RakLib / versioned codec
                           | binary IPC
                           v
                     Rust simulation
                           |
                       world / WAL

PHP gateway -> отдельные процессы PHP-плагинов
```

`src/` содержит текущую Rust-симуляцию, цикл сервера, игроков, плоский генератор, взаимодействия и сохранение. `gateway/` содержит обязательный PHP-сетевой слой, авторизацию, палитры, инвентарные операции и plugin host. `test-client/` — отдельный JS-клиент; `codec/` — экспериментальные преобразователи, не доказательство поддержки новых версий.

Сетевой runtime ID выбирается для конкретного профиля. Внутреннее состояние мира не должно зависеть от клиента. Пока реестр Rust ограничен 12 значениями u8; расширение требует одновременной миграции IPC и storage, а не только загрузки полной BedrockData.

У текущего состояния мира один владелец. Региональная многопоточная симуляция и полный Rust gateway ещё не реализованы. Основные ограничения и очередность изменений: [AUDIT_AND_ROADMAP.md](AUDIT_AND_ROADMAP.md). План устранения обязательной PHP-зависимости: [RUST_MIGRATION.md](RUST_MIGRATION.md).
