# Проверка официальным Minecraft Bedrock

Это сценарий проверки, не сообщение об успешно пройденном входе.

```bash
git pull --ff-only origin main
./start.sh --check-source
./start.sh --unit
./start.sh --playtest --version 1.26.20
```

Версия официального клиента должна соответствовать выбранному профилю. Для разбора текущей ошибки используется 1.26.20 / 975. Режим playtest создаёт отдельную конфигурацию и карту, включает online-auth/encryption и Creative, слушает 19132/UDP на локальной сети. Порт на роутере он не открывает. Сейчас max-players=1; взаимная видимость игроков ещё не реализована.

До строки Listening сервер проходит проверки настоящих пакетов и NBT. Ошибка INTEGRATION FAILED на этом этапе — ещё не результат клиентского входа. Не отключай проверку ради открытия порта.

В клиенте укажи IP компьютера в домашней сети, не 0.0.0.0. Для подключения с того же компьютера используется 127.0.0.1. Проверь разрешение UDP в локальном firewall, не публикуя сервер в Интернет.

## Игровая проверка

Вход -> трава -> движение/прыжок -> хотбар -> установить и разрушить блок -> открыть инвентарь -> чат -> /spawn -> выйти и зайти снова. Проверку сохранения провести на тестовой карте: поставить блок, штатно остановить сервер командой stop, запустить с той же конфигурацией и проверить блок.

В отчёте отдельно указывай точную версию Minecraft, Git commit, этап сбоя и серверный trace. Журнал диагностики читается командой:

```bash
python3 tools/playtest-report.py data/playtest.jsonl > playtest-report.json
```

Не публикуй JWT, access/refresh tokens, приватные ключи и каталог .client-auth. Успех headless-клиента не проверяет изображение, интерфейс и управление официальной игры.
