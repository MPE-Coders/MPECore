# Протокольные профили

Список профилей находится в resources/protocol-catalog.json; конкретные NBT/JSON-файлы — в resources/protocols/<id>.json. Наличие файла профиля не подтверждает успешное подключение соответствующего клиента.

Для текущего исправления используется Minecraft Bedrock 1.26.20 / protocol 975. Патч не добавляет новых версий и не снимает блокировку профилей без проверенных данных. Не подставляй палитру соседней версии ради прохождения StartGame.

Нужно различать: внутренний BlockStateId, типизированное каноническое состояние, block runtime ID клиента, item runtime ID и network ID конкретного стека. JSON/NBT-каталог не реализует поведение блоков и предметов.

`./start.sh --doctor` проверяет профили выбранной конфигурации настоящими установленными кодеками; это не клиентский вход. Workflow preflight проверяет профили 671, 766, 975 и 1001 по отдельности. Результат каждого запуска находится в Actions, не определяется самим наличием workflow.

Подробности данных и pinned upstream: [UPSTREAM_DATA.md](UPSTREAM_DATA.md).
