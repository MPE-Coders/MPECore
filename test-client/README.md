# MPE Test Client

Отдельный headless Bedrock/RakNet-клиент. Требуются Node.js >=24 и npm. Он не заменяет официальный Minecraft и не проверяет рендеринг GUI.

Из корня монорепозитория:

```bash
./tools/node-install.sh
./client 127.0.0.1 19132 --version 1.26.20 --scenario creative --report client-report.json
```

По умолчанию используется online sign-in. .client-auth содержит кэш авторизации: не публиковать. --offline предназначен только для отдельного локального сервера с явно выключенным online-mode.

connect проверяет получение StartGame/спавна/чанка. smoke добавляет чат и движение. creative дополнительно использует хотбар, окно инвентаря и обычные игровые пакеты установки/разрушения. edit использует операторский /setblock. Изменяющие мир сценарии запускай только на тестовой карте: при обрыве cleanup может не завершиться.

```bash
./client 127.0.0.1 19132 --ping-only
./client --list-protocols
```

Ping подтверждает только discovery, не вход. Exit 0 означает прохождение выбранного сценария, 1 — провал, 2 — ошибку аргументов/старта. JSON-отчёт фиксирует полученные подтверждения. --palette /absolute/path/file.nbt включает независимую проверку палитры; без файла используется явно обозначенное сопоставление, сообщённое сервером.

Сценарий и тестовые схемы не являются заявлением, что все перечисленные протоколы поддерживаются сервером. Поддержка server profiles ограничивается их собственными данными и проверками.
